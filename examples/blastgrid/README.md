# Blast Grid 64 soundtrack

The 13 songs of the game *Blast Grid 64* by Marcin Spoczynski, imported into
SIDTracker projects (`BG_<SONG>.sidt`) from the game's own song sources with
`tools/blastgrid/bg2text.py` (`make blastgrid`, docs/blastgrid-import.md):
the C64 version's dual-SID arrangement and SID instruments, editable as
patterns, instruments and tables.

Music by Marcin Spoczynski, included in SIDTracker with his permission.
